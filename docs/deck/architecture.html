Architecture

Project Dispatch: from open data to the demo, all processing on an IBM LinuxONE instance.
Open data (outside)
NYC EMS incidentsNYC Open Data API, 2017-2022 (2021 trains, 2022 tests)
Weather and calendarOpen-Meteo, US holidays
Zones and contextCensus ACS, health data, ZIP zone boundaries, hospitals, firehouses
Street routingOSRM public server (OpenStreetMap), cached on disk
IBM LinuxONE instances390x big-endian, z17-generation, z/VM 7.3, 3 CPUs, 8 GB, JupyterLab; Python 3.12
1 Data pipelinepandas, NumPy. Streams EMS by year, joins weather and zone data. Peak 1.0 GB for two years
2 Forecast8 LightGBM Poisson models: critical and other calls per ZIP zone, 30 min to 3 h. Saved as text files
3 Risk indexNeed-weighted demand x vulnerability, 0-100 per zone
4 Positioning policyExpected-coverage objective, SciPy assignment, one unit per borough, 30-minute cycle
5 ReplayMinute-by-minute replay of real 2022 calls: static, scheduled, forecast, oracle
6 ExportUnit timelines, call lifecycles, zone shading, street routes as JSON
7 Web demoReact, Leaflet, Vite; served from the instance (port 5173); plays back the export
AI accelerator testnnpa / zDNN via Snap ML: benchmarked vs CPU LightGBM, slower, so scoring stays on the CPU. 33 tests pass
