The Stack on IBM Z

Every layer below runs on the LinuxONE instance, from raw data to the demo.
DemoReact + Leaflet map, served from the VM; real street routes (OSRM)
DecisionsPositioning policy (SciPy assignment) and minute-by-minute replay of real 2022 calls
Forecast8 LightGBM Poisson models: critical and other calls per ZIP zone, 30 min to 3 h
Data and Pythonpandas, NumPy, SciPy; NYC Open Data, Open-Meteo, Census
BASE OF THE STACKIBM LinuxONEs390x (big-endian), z17-generation, z/VM 7.3, 3 CPUs, 8 GB, Jupyter

How we use IBM Z

End to endTraining, scoring, replay and demo all run on the instance. 33 of 33 tests pass on s390x.
1.0 GBpeak memory for two years of data: built to fit the instance, not the other way round.
PortableModels saved as text files, because pickles do not move between x86 and big-endian s390x.
nnpaOn-chip AI accelerator found and driven through Snap ML. Benchmarked at 0.3 to 0.7x the CPU, so we kept the faster CPU path.
Measured on the VM: accelerator benchmark, memory test and test suite (screenshots in the repo).
